# Audio ML Note

面向零基础中文读者的音频信号处理与机器学习课程：从「声音是什么」讲到梅尔频谱、MFCC 与频域统计特征，全程围绕一个项目——**让程序听 1 秒钟的音乐片段，判断它来自古典、爵士还是摇滚。**

## 正式版里有什么

- **23 篇文章**，分成五组：01—05 认识声音与数字录音，06—10 把录音变成可计算片段，11—15 进入时间—频率表示，16—20 整理成模型输入，21—23 用少量数字概括频谱。
- **122 张配图**，每张同时有电脑版（880 px 横排）和手机版（420 px 竖排），由同一份数据、同一段代码生成，正文用 `<picture>` 按屏幕宽度切换。
- **23 个可运行脚本**（`课程代码/lessons/`）与一个逐课累积的工具包 `soundlab/`。正文里的每个数字都能在对应脚本的输出里找到。

## 配图约定

- 波形、频谱、声谱图一律来自真实计算，不画凭空示意图；素材优先取课程音频，其次是与正文严格对应的合成信号。
- 声谱图用 magma 色标（librosa 与音频论文的惯例），线图用通过色觉障碍校验的分类色。
- 时间和频率是连续轴，画曲线或谱线；只有横轴是真正的离散类别时才用柱状图。
- ASCII 图只允许用于命令行和目录树，其余一律画成 SVG。
