# Audio ML Note

面向中文读者的音频信号处理与机器学习课程笔记。内容从声音与波形、采样和量化开始，逐步进入音频特征、分帧加窗、时域分析与傅里叶变换。

## 课程文章

[进入 23 篇课程博客总目录](NotebookLM课程博客_重写版/README.md)

每篇文章均包含：

- 适合中文技术阅读的结构化讲解；
- 数学公式与具体代数例子；
- 可运行的 Python 示例；
- 中文标注的工程图与学术风格示意图；
- 原课程视频、PDF 或 Notebook 的复现入口。

## 配图规范

- 纯白背景，避免装饰性渐变、发光和 3D 效果；
- 数据图主色采用 MATLAB 默认蓝 `#0072BD`；
- 中文字体在导出时显式绑定，避免乱码和缺字；
- 频谱、量化、RMS 与 ZCR 等图由公式或课程音频确定性计算生成。

## 写作规范

面向零基础读者的写作与审校规则、评分标准和检查脚本，放在项目内的 skill 里，Claude Code 可以直接加载：

```
.claude/skills/audit-and-rewrite-popular-science/
```

核心约定是让文章**自然加深，但不把写作结构写在标题里**：从生活问题出发，先用日常语言讲清机制，专业名称在需要时逐个出现，公式、代码与适用边界顺着内容放到后文。第 01～05 课的新改写见 [零基础版_01-05](NotebookLM课程博客_重写版/零基础版_01-05/README.md)。
