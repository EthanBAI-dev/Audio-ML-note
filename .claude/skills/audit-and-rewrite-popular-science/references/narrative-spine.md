# 叙事主干：让文章有往前推的力

零基础规则解决的是「这一句读不读得懂」。这份文件解决的是另一个问题：**每一句都读得懂，整篇却没有理由读下去。**

症状很好认——小标题是「A：A 是什么」「B：B 是什么」「C：C 是什么」，然后对比，然后小结。术语关全过，图也都对，但它是一份分类学导览，不是一篇文章。

## 1. 动笔前先写一句 ABT

ABT 是 Randy Olson 从科学传播里总结的叙事骨架，MIT Communication Lab、SESYNC 等都把它当标准工具在教。三个连接词，一句话：

> **……，而且……，但是……，所以……**

- **And**：读者已经接受的前提。不需要说服，只需要建立共同起点。
- **But**：转折。**这是整篇文章存在的理由。**没有 But 就没有文章，只有说明书。
- **Therefore**：因此要做什么／因此得到什么。

第 01 课的 ABT：

> 我们想让程序分辨狗叫、汽车和人声，**而且**录音进电脑之后确实就是一串数字，
> **但是**同一串数字有三种整理方式，每一种都会丢掉另外两种留下的东西，
> **所以**得先问清任务需要哪条证据，再决定给程序看哪一种。

写在正文最上方，用 HTML 注释，读者看不到，改稿的人一眼能看到：

```markdown
<!-- abt: 我们想让程序分辨狗叫、汽车和人声，而且录音进电脑之后确实就是一串数字，但是同一串数字有三种整理方式，每一种都会丢掉另外两种留下的东西，所以得先问清任务需要哪条证据，再决定给程序看哪一种。 -->
```

`check-readability.mjs` 会检查这行在不在、三个连接词齐不齐。

两条判断标准：

- **But 里必须真的有东西坏掉。**「但是它还有更多细节」不是转折，是过场。「但是那声敲击被十秒钟一平均，图上完全找不到了」才是。
- **如果 But 拿掉，文章还成立**，说明这篇本来就没有主干，得重想，不是重写。

## 2. 每一节的结尾要造出下一节的需要

分类学导览的每一节都是「定义 + 一句免责声明」结束的：

> 但它也有看不清的东西。同样是一条抖动的曲线，你很难一眼看出这段声音里"高音多还是低音多"。

读者读到这里可以合上页面——这一节自洽了。改成让它欠着：

> 那"高音多还是低音多"呢？这条曲线上下抖得再详细，也答不了。
> 想回答它，只能换一种问法。

差别不在措辞，在**这一节最后一句是收口还是开口**。开口的写法：把下一节要解决的问题，用读者自己会问出来的方式问出来。

节与节之间靠这个连，不靠「接下来我们看」这种过渡句。

## 3. 小标题写发现，不写题目

| 写题目（分类学导览） | 写发现（有主干） |
| --- | --- |
| 波形：保留每一个瞬间的变化 | 最老实的记法：每一个瞬间都记下来 |
| 频谱：突出声音由哪些高低成分组成 | 不管先后，只问里面有哪些成分 |
| 三种表示怎么选 | 先问任务需要哪条证据，再挑表示 |

判断办法：**只读小标题，能不能读出一条论证？** 能读出「先这样→不够→于是那样→代价是→所以按任务挑」，就是主干；只读出「A、B、C、对比」，就是目录。

小标题里不要出现「介绍」「概述」「简介」「基本概念」，也不要用「X 与 Y」这种并列名词短语当标题——那是词条名，不是发现。

## 4. 连贯性：别人家的货要删掉

Mayer 的连贯性原则（coherence principle，200 多组对照实验的结论之一）：**加进去的相关但非必需的材料，会降低学习效果**，不是锦上添花。

在这套课里，它有一个非常具体的形式：

> **如果一个概念在另一课有主场，这一课最多给它一句话加一个链接，不给它 H2，也不给它 H3。**

第 01 课曾经用四个 H3 讲分帧、先验、预处理、数据泄漏。分帧是第 06 课的主场，那三个 H3 就是别人家的货。删掉它们，文章不会缺，只会更紧。

自查：把每个 H2／H3 的题目列出来，逐个问「这一节被删掉，这篇的 ABT 还成立吗？」成立的就删。

## 5. 举例要用课程自己的素材

泛泛的行业例子（语音识别、说话人验证、机械故障诊断、音乐标签……）读起来专业，但读者手上没有这些数据，验证不了，也接不上后面的项目。Mayer 把这类东西叫 seductive details：有趣、相关、但会挤占注意力。

这门课有自己的三段录音（`debussy.wav` / `duke.wav` / `redhot.wav`）和一个贯穿的项目。**举例先从它们里挑**，挑不出来再往外找。好处是每一课的例子都在为最后那个分类器攒材料。

## 6. 同一件事不说两遍

开头只有一行导读，写这篇要解决的问题，也就是 ABT 里「但是」那一半。**不要再加一行「读完能做到」**——它和导读、小结互相复述，还占掉了开头最值钱的位置。

小结负责回答开头那个问题，并且**说出一件正文里没直接说过的话**，通常是这条结论在下一课或在项目里怎么用。如果小结只是把前面几节的标题连起来重说一遍，删掉它比留着好。
