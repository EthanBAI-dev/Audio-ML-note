# 采样率与位深：44.1 kHz 和 16 bit 决定了什么？

> **导读：** 数字音频既要决定“每秒量多少次”，也要决定“每次记多细”。本文从采样率与混叠讲到量化、位深和参数取舍，说明 44.1 kHz、16 bit 及更高参数分别解决什么问题。

下载或购买音乐时，页面上常写着 "44.1 kHz / 16 bit"，高清版本则写着 "96 kHz / 24 bit"，价格还更贵。这两个数字分别在说什么？数字更大是不是就一定更好？

在回答之前，先看一个乍看无关的现象。看汽车广告或老电影时，你多半注意过一件怪事：车明明在向前开，车轮却看起来在**慢慢倒转**。车轮当然没有真的倒转，是画面出了问题。

这两件事的背后是同一个道理：**把连续变化的世界，用一格一格的数字记录下来时，会发生什么。**

## 采样与量化：连续声音变成数字的两个步骤

麦克风输出的是连续变化的电压：任何一个瞬间它都有一个值，值可以是任意小数。但计算机存不下"任何一个瞬间"，也存不下"任意小数"。

所以它只能做两件退让：

1. 不是每时每刻都记，而是**每隔一小段时间量一次**。
2. 量到的数不是原样保存，而是**靠到最近的那个档位上**。

这两件事，就是那两个数字的来历。

可以拿录像来类比。摄像机不是连续记录，而是每秒拍 24 张或 60 张照片，放起来看就像连续的。声音也一样，只不过快得多——一秒钟要"拍"四万多次。

## 采样率：一秒钟量多少次

一秒钟测量多少次，叫**采样率**。44100 Hz 就是每秒测量 44100 次。

那为什么偏偏是四万多次？这和"一秒钟拍几张照片才不会看出卡顿"是同一类问题：**要记录的东西变得越快，就必须量得越勤。**

人耳通常能听到的范围大约从每秒振动 20 次到 20000 次。要保留接近两万次的变化，一秒钟测四万多次是数学上的最低要求。这背后有一条明确的规则：**测量次数必须高于要记录的最快变化次数的两倍。** 这里的“两倍”不是为了正好抓住一个高点和一个低点，而是为了让不同快慢的变化不至于留下完全相同的数字。

## 混叠：采样太慢会把高频看成低频

现在回到车轮。摄像机每秒拍 24 张照片。假设车轮上有一根辐条，它转得很快，在两张照片之间刚好转了将近一整圈——比如转了 350 度。那么在照片上看，这根辐条从原来的位置**往回退了 10 度**。一张张连起来看，车轮就像在慢慢倒转。

轮子当然在正着转。问题出在**拍得太慢**：真实的快速运动，在这样一次次测量之后，伪装成了一个完全不同的慢速运动。

声音里会发生同样的事：**一个太高的音，如果采样不够勤，会在数字里变成一个原本不存在的低音。** 这种"高音伪装成低音"的现象叫**混叠**。

混叠最麻烦的一点是：

> 它发生在测量的那一刻，事后无法修复。

因为伪装完成之后，这个假的低音和一个真的低音在数据里长得完全一样，没有任何办法把它们区分开。把文件"升级"到更高的采样率，只是增加了点的数量，救不回已经丢失的信息。

正因为无法补救，真实的录音设备会在测量**之前**先加一道处理：**把那些太高、注定记不清楚的成分先过滤掉**。这道处理叫**抗混叠滤波**。宁可不要那部分内容，也不能让它伪装成假的低音混进来。

一个振动每秒重复多少次，叫它的**频率**。用这个名字，就可以把前面的规则写成公式。

写成公式，采样周期为 $T_{\mathrm{s}}$、采样率为 $f_{\mathrm{s}} = 1/T_{\mathrm{s}}$ 时，离散序列为 $x[n] = x(nT_{\mathrm{s}})$。若连续信号在 $f_{\max}$ 以上没有频率成分，理想重建的条件是

$$
f_{\mathrm{s}} > 2f_{\max}
$$

$f_{\mathrm{s}}/2$ 称为 **Nyquist 频率**，是采样后能够无歧义表示的最高频率。工程上不会把目标频带机械地贴到这条边界：真实的抗混叠滤波器不可能在某个频率上垂直截断，必须留出**过渡带**。这正是 CD 采用 44.1 kHz 而不是刚好 40 kHz 来覆盖 20 kHz 带宽的原因之一。

至于伪装后的频率落在哪里，可以用

$$
f_{\mathrm{alias}} = \min_{k \in \mathbb{Z}} \left|f - k f_{\mathrm{s}}\right|
$$

计算，即在 $f$ 与所有 $f_{\mathrm{s}}$ 整数倍之间取最小距离。例如 $f = 7$ Hz、$f_{\mathrm{s}} = 10$ Hz，取 $k=1$ 得 $f_{\mathrm{alias}} = |7 - 10| = 3$ Hz，与图 2 一致。

## 量化与位深：每次测量能记多细

第二个数字是位数，比如 "16 bit"。它管的是另一件事：**每次测量的结果，允许用多少个档位来表示。**

用量身高打个比方。如果尺子上只有整厘米的刻度，那么 172.4 cm 只能记成 172 cm，误差 0.4 cm。如果尺子细到毫米，误差就降到 0.05 cm 以内。

数字音频里，档位有多少个由位数决定：8 位是 256 个档位，16 位是 65536 个，24 位是一千六百多万个。

*图 3：左图的蓝色阶梯是明显的大台阶，右图几乎贴着灰色原曲线走。档位数从 8 变成 32，改动量就差了这么多。*

把连续数值靠到最近档位的操作叫**量化**，靠过去时改动的那一点点叫**量化误差**。档位越密，误差通常越小。它有时表现得像一层轻微杂音，在信号很弱、又没有做额外处理时，也可能形成和声音相关的失真，不能一概当成均匀底噪。

$B$ 位编码最多表示 $2^B$ 个码字。若采用把 $-1$ 和 $+1$ 都当作网格端点的教学式量化器，步长为

$$
\Delta = \frac{2}{2^B - 1}
$$

取 $B=3$：8 个等级，$\Delta = 2/7 \approx 0.2857$。样本 $x = 0.37$ 四舍五入到最近网格点：

$$
q = -1 + \Delta \operatorname{round}\!\left(\frac{x+1}{\Delta}\right) \approx 0.4286
$$

误差 $e = x - q \approx -0.0586$。

```python
import numpy as np

def quantize_endpoint_grid(x, bits):
    """教学用端点网格量化器，不代表所有 PCM 编码约定。"""
    levels = 2 ** bits
    x = np.clip(np.asarray(x), -1.0, 1.0)
    step = 2.0 / (levels - 1)
    code = np.round((x + 1.0) / step)
    return code * step - 1.0
```

实际文件通常把每次测到的数直接按顺序保存，这种未压缩的存法叫 **PCM**。不同 PCM 格式可能采用不同端点与舍入约定，例如有符号整数的正负范围并不完全对称；做逐位比较时必须查阅具体格式定义。

如果用“原来的声音有多强”除以“量化误差有多强”，就得到**信号与量化误差之比**（SQNR）。对理想均匀量化器与达到最大可记录幅度的正弦输入，常用近似

$$
\mathrm{SQNR} \approx 6.02B + 1.76\ \mathrm{dB}
$$

16 位的理论值约 98.08 dB。**这是理论上限，不是设备保证值**：模拟前端噪声、失真、时钟抖动和有效位数都会使实测值低于它。

## 参数取舍：数字更大不一定更合适

不完全是。提高这两个数字，都要付出代价：在声道数和位深不变时，采样率翻倍会让未压缩文件大小翻倍，许多后续计算也会近似增加一倍；位数增加，文件同样会变大。

未压缩 PCM 的理论码率是 $R = f_{\mathrm{s}} B C$。这里 $B$ 是每次测量使用的位数，也叫**位深**；$C$ 是同时保存几路声音，也就是**声道数**。立体声有左、右两路，所以 $C=2$。44.1 kHz、16 bit、立体声就是

$$
44100 \times 16 \times 2 = 1{,}411{,}200\ \mathrm{bit/s}
$$

10 分钟约 105.84 MB（十进制计数，不含文件头）。

而收益是有条件的：

- **提高采样率，只在你真的需要那些更高的成分时才有意义。** 如果机械诊断只关注 4 kHz 以下，16 kHz 采样在滤波条件合适时通常已经足够；若目标是超声或极短、突然出现的变化，则必须显著提高。
- **提高位数，只在录音链路本身足够安静时才有意义。** 如果房间里的环境声、麦克风自身的沙沙声（这些统称**噪声**）已经比档位间隔大得多，那么再细的档位，也只是在更精确地记录这些杂音。录音时常用 24 位，是因为它允许把录音增益设得保守一些、给突然变大的声音留出余量，同时仍保持很低的量化误差；发布时再转成 16 位，是常见做法。

还有一条容易被忽略的纪律：**学习判断规律的程序（也就是模型）最终收到的处理结果必须一致。** 例如模型按 16 kHz 的录音训练，那么上线时即使收到 44.1 kHz 文件，也应该先用同一套规则转换到 16 kHz；不能直接把两种数字含义不同的数据混着交给模型。

## 小结

把连续的声音变成数字，只做了两个决定：**多久量一次**（采样率，决定能无歧义记录到多高的成分）和**每次量得多细**（位深，决定档位的精度）。

采样太慢会造成混叠，而混叠一旦发生就无法修复，所以真实设备总是先滤波再采样。档位太粗会带来由量化误差形成的杂音，但当现场底噪本来就更大时，加位数并不会带来实际收益。

顺带一提，采样率还决定了一段录音里有多少个数字，也就决定了[第 01 篇](01-波形频谱与声谱图-电脑识别声音时该看什么.md)里分帧要处理多长的序列。这两个数字不是越大越专业，而是应该**刚好覆盖任务所需的信息**，并与存储、延迟和计算成本相匹配。
