# 第 11～15 课：零基础知识主线改写版

本组属于[课程总纲](../课程总纲/README.md)的第 11-15 阶段：**从波形进入时间—频率表示**。

每篇末尾的「动手做」对应[课程项目《三首曲子，一个分类器》](../课程项目/README.md)的进入频率（第 11—15 步）。

完整方法见[《零基础科普文章改写与配图工作流》](../零基础改写与配图工作流.md)。本批继续采用“一篇只解决一个核心问题、正文自然递进、图承担推理步骤”的方式。

## 文章与边界

| 课 | 文章 | 本篇只解决什么 |
|---|---|---|
| 11 | [复数的模与相位：为什么声音中的振动需要二维坐标？](11-复数-一个数怎样同时装下强度和起点.md) | 用横纵坐标、模与相位解释复数怎样保存振动的强弱和起始位置 |
| 12 | [傅里叶变换为什么使用复数：怎样同时测出频率强度与起始位置？](12-复数形式的傅里叶变换-把强度和起点写进一个系数.md) | 从两条互相补足的测试波进入复数傅里叶系数与可逆重建 |
| 13 | [离散傅里叶变换（DFT）：有限样本怎样变成一格一格的频率？](13-离散傅里叶变换-把无穷个频率砍成有限个.md) | 解释有限样本、离散基、频率格、共轭对称和 DFT/FFT 的关系 |
| 14 | [用 Python 正确读取 FFT 频谱：频率轴、单边幅值与归一化](14-用Python提取频谱-四种声音的频率成分有什么不同.md) | 修正 Hz 轴、单边幅值、窗归一化，并区分相对 dB 与功率谱密度 |
| 15 | [短时傅里叶变换（STFT）：怎样同时看见频率与出现时间？](15-短时傅里叶变换-整段频谱为什么找不到声音发生的时间.md) | 解释移动短窗、矩阵尺寸、时间—频率取舍和补边默认值 |

11 不提前讲傅里叶积分；12 不展开离散频率格；13 不承担完整 Python 幅值读取；14 只分析整段或单帧频谱；15 再引入频率随时间排列。每篇可以独立阅读，上一课只作为可选背景。

## 配图

共 20 张知识图，每张由同一份数据生成桌面和手机两个版式：

- `figures/desktop/`：880 px，保留并排比较。
- `figures/mobile/`：420 px，改成纵向构图；缩到 360 px 正文宽度后，最小有效字号不低于 12 px。

真实乐器、噪声和 STFT 热力图来自课程音频或明确参数的计算结果；复平面、DFT 基与流程图属于概念示意。手机端保留图形和说明，不把桌面图机械缩窄。
