# 从声音到机器学习特征：23 课课程总纲

> **导读：** 这套课程先说明声音分类为什么不能直接照搬图片分类，再从声音怎样产生、怎样被电脑记录开始，逐步走到分帧、傅里叶变换、声谱图、梅尔频谱、MFCC 和频域统计特征。目标不是背下一组函数名，而是知道每一步在计算什么、保留什么信息、参数或矩阵方向写错后会发生什么。全程围绕一个项目展开：让程序分辨古典、爵士和摇滚。

## 我们到底要做出什么？

这套课程有一个贯穿始终的目标：**让程序听 1 秒钟的音乐片段，判断它来自古典、爵士还是摇滚。**

课程自带的 `debussy.wav`、`duke.wav`、`redhot.wav` 正好是这三种风格。人一听就分得出，但要让程序分出来，就必须把"听起来不一样"翻译成可计算的数字——这正是 23 课在做的事。

每一课都对应 `课程代码/` 里的一个脚本，是这个项目的一步。23 步做完，你手里会有：

- 一套自己写的音频特征工具包（不是调库调出来的）；
- 一张每行一个片段、每列一个特征的表；
- 一份说明：三种风格在哪些特征上差别最大，以及为什么。

完整的项目说明、目录结构和 23 步的对应关系，见[课程项目：三首曲子，一个分类器](../课程项目/README.md)。

**最后一步不是训练一个深度模型。** 这套课程的范围停在"为识别程序准备可信的输入"，所以收尾要回答的是：我算出来的这些数字，真的够程序分辨三种风格吗？

## 需要什么环境

**装一次，23 课全程不用再动。** 需要 Python 3.10 或更新的版本，五个包一行装完：

```bash
python -m pip install numpy scipy matplotlib librosa soundfile
```

五个包各管一件事：`numpy` 负责数组计算，`scipy` 提供信号处理的现成函数，`matplotlib` 画图，`librosa` 读音频并提供一批音频专用函数，`soundfile` 是 `librosa` 读写文件时实际调用的那一层。**这门课不需要 API Key，也不需要 `.env` 文件**——所有计算都在你自己的机器上跑完。

课程自带的十段音频在 `source_course/audio_resources/` 下，正文里出现的 `debussy.wav`、`duke.wav`、`redhot.wav` 都在里面。

全课程的输出都是在下面这组版本上实测出来的。你的版本不同，最后一两位小数可能对不上，结论不会变：

| 包 | 版本 |
|---|---|
| Python | 3.12.10 |
| numpy | 2.5.2 |
| scipy | 1.18.1 |
| matplotlib | 3.11.1 |
| librosa | 1.0.0 |
| soundfile | 0.14.0 |

环境就这些。**每一课的实验都写在那一课里**，这里不提前跑。

## 这套课程想解决什么问题？

电脑收到的声音只是一串随时间变化的数字。要让后续程序从中分辨说话、音乐、环境声或设备状态，我们需要把这些数字整理成能够比较的证据。

本系列沿着一条完整主线前进：先看懂声音怎样被记录，再把录音切成短片段；接着找出片段中有哪些高低成分，并把结果整理成适合后续程序使用的数字表；最后用少量数字概括这些成分的分布。

课程的重点停在“为声音识别程序准备可信的输入”。识别程序怎样训练、怎样上线，不在本系列范围内。

## 五组课程分别讲什么？

### 第 01—05 课：认识声音与数字录音

从[第 01—05 课](../零基础版_01-05/README.md)先认清课程要解决的声音分类问题，再学习声音怎样产生、波形记录什么、仪器读数和人的听感有什么差别，以及连续声音怎样经过采样和量化变成数字。第五课再建立音频特征的分类地图，为后面选择计算方法做准备。

### 第 06—10 课：把录音变成可计算片段

[第 06—10 课](../零基础版_06-10/README.md)把整段声音切成许多短片段，再观察每段的最大变化、整体强弱和穿越中线的次数。最后建立“复杂声音可以拆成许多快慢不同的振动”的直觉。

### 第 11—15 课：从波形进入时间—频率表示

[第 11—15 课](../零基础版_11-15/README.md)解释怎样测出每种振动的强弱和起始位置，再把整段分析改成移动短窗分析。学完后不仅会调用**傅里叶变换**，还知道横轴怎样换成真实的高低位置，以及观察时间和观察成分细节为什么需要取舍。

### 第 16—20 课：把频谱整理成模型输入

[第 16—20 课](../零基础版_16-20/README.md)把大量高低成分重新汇总，使数字表更接近人的听觉，也更适合交给后续程序。这一组会实现**对数梅尔频谱**和 MFCC，并加入描述前后变化的数字，同时记录足以复现结果的参数。

### 第 21—23 课：用少量数字概括频谱

[第 21—23 课](../零基础版_21-23/README.md)把一整列高低成分概括成少量数字，回答三个问题：低处与高处哪边更强、分布中心在哪里、声音成分铺得有多开。重点是让计算方法、坐标方向和图上含义保持一致。

## 学完后能够做什么？

- 看懂声音随时间的曲线、高低成分图和高低成分随时间变化的图。
- 用 Python 把录音切成短段，寻找其中的高低成分，并构建常用声音特征。
- 看懂数字表中哪一边表示时间、哪一边表示高低位置，建立正确坐标。
- 发现记录速度、分析窗口、边缘处理、数值单位和除零造成的错误。
- 从任务真正需要的声音证据出发，选择更合适的程序输入。

这套课程最终希望读者建立一种工作习惯：不要把库函数的输出当成答案，而要能说明这个结果从哪里来、代表什么、在什么条件下才值得相信。
