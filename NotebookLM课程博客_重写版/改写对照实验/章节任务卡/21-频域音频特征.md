# 第 21 课任务卡：频域音频特征

- 源文件与范围：
  - 主线：`source_course/21 - Frequency-Domain Audio Features/Frequency-domain audio features.pdf`，46 页；没有配套的可执行 `.ipynb`。
  - 逐页文字：`NotebookLM课程博客_重写版/PPT内容/21-Frequency-Domain-Audio-Features.md`。
  - 补充参考：`notebooklm博客/ダウンロード (14).md`。它是 NotebookLM 生成的 Markdown 博客稿，不是 Jupyter Notebook。
- 上一课交进来：读者已经会把一段录音切成帧，并能得到每一帧的频谱或 MFCC。
- 读者问题：一整列频谱有上千个数，能不能用少数几个数回答更直接的问题？
- 一句话结果：带能量比回答“低频相对高频有多少”，频谱质心回答“频率重心在哪里”，频谱带宽回答“频率围绕重心铺得多开”；三者观察的是频谱的不同侧面，不能互相代替。
- 本课拥有的新概念：频带能量比、分界频率、频谱质心、频谱带宽；每个特征都是“每帧一个数”。
- 只回顾：波形、分帧、加窗、STFT、频率格、幅度与功率只回链，不重新推导。
- 明确留给后课：第 22 课实现 BER 并测三段音乐；第 23 课实现质心与带宽并和库函数对齐。本课不提前画真实音乐的三条特征轨迹。
- 按源材料排列的讲解块：
  1. 从波形到频谱，再从一列频谱压成一个特征值。
  2. 约定一帧的第 `n` 个频率格为 `m_t(n)`，一共有 `N` 格。
  3. BER：在分界频率两边分别累计功率，再做比值。
  4. 质心：用幅度给真实频率 `f[n]` 加权，求频率重心。
  5. 带宽：量每个频率离质心多远，再按幅度加权。
  6. 三个数分别适合回答什么问题，以及它们各自看不见什么。
- 必要校正：
  - 质心和带宽必须使用真实的 Hz 频率 `f[n]`；只用序号 `n` 得到的是“第几格”，单位不是 Hz。
  - 源材料的带宽公式是平均绝对距离（`p=1`），第 23 课调用的 librosa 默认值是均方根距离（`p=2`）。本课先给统一的 `p` 次距离写法，并明确两种定义都存在、数值不能混用。
  - “明亮”只作为频谱质心常见的听感线索，不写成一一对应的判决。
- 实验问题：能不能造出“质心相同但带宽不同”以及“带宽相同但质心不同”的频谱，证明三个特征不能互相替代？
- 验收标准：
  1. 三个公式各在一个离散合成频谱上手算，输出中间的分子、分母和最终值。
  2. 至少有一对合成频谱质心相同、带宽不同；另一对带宽相同、质心不同。
  3. BER 明确使用功率，质心和带宽明确使用幅度。
  4. 所有正文数字和配图来自同一次 `--dump`。
