# 第 01 课任务卡：课程导论

- **源文件：**`source_course/01 - Overview/Audio Signal Processing for Machine Learning.pdf`，第 1—15 页。
- **上一课交入：**无；这是系列入口。
- **读者问题：**电脑能判断照片里是不是猫，为什么让它判断一段声音时，还要先学习声音怎样被记录和处理？
- **本课结果：**读者知道这套课解决什么问题、按什么路线前进、代码在哪里，并成功确认三段项目素材。
- **本课拥有：**课程目标、声音应用、课程路线、理论与代码并行、工具与读者要求。
- **只预告：**波形、时域/频域特征、傅里叶变换、声谱图；只在路线图出现，不解释定义和算法。
- **明确后移：**波形到 02；声音强弱和音色到 03；数字录音到 04；特征分类到 05；傅里叶到 10；声谱图提取到 15—16。

## 按源 PPT 排列的讲解块

1. 图片分类与声音分类：两者都要把输入交给一个负责判断的程序，但声音里的证据需要沿时间读取和整理。
2. 应用：声音分类、语音识别/说话人确认、降噪/音频修复、音乐信息检索、乐器和情绪识别。
3. 课程地图：声音与波形 → 数字录音 → 特征 → 傅里叶与时频表示 → 可解释的频域统计。
4. 学法：每个概念既讲原理，也有能运行的代码；代码和素材均在仓库中。
5. 工具：Python、NumPy、librosa 等；安装统一指向课程总纲，不在本课重复。
6. 学习结果、适合的读者和前置要求；说明原课假设中级 Python，本重写降低音频知识门槛，但仍需基本 Python 阅读能力。
