# 第 14 课任务卡：用 Python 提取频谱

- 源文件与范围：`source_course/14 - Extracting the Discrete Fourier Transform/Visualising the Power Spectrum.ipynb`，cell 0—13；正文按单元格顺序展开。
- 上一课交进来：有限的 `N` 个样本可以通过 FFT 得到 `N` 个 DFT 系数；数组位置可以换成 Hz；真实录音的后一半是共轭镜像。
- 读者问题：公式已经能算了，但真正把小提琴、钢琴、萨克斯和噪声交给 Python 后，怎样得到一张可以正确阅读的频谱？
- 一句话结果：依次载入四段真实声音，用 `np.fft.fft` 计算、用 `np.abs` 取每个复数系数的模，再用配套频率轴查看低频部分；乐器会出现成列的突出峰，噪声则铺在较宽的频率范围里。
- 本课拥有的新概念：用 NumPy 提取真实录音的幅度谱；`f_ratio` 只控制显示范围；原始 FFT 模值与相对 dB 各自能回答什么。
- 只回顾或预告：采样率回链第 04 课；FFT、频率格、单边镜像回链第 13 课；不重新推导公式。
- 明确留给后课：第 15 课负责分帧、加窗、STFT、时间—频率取舍；第 16 课负责声谱图；Mel、MFCC 和频谱统计继续留给 17—23。
- 按源材料排列的讲解块：
  1. 导入库并定位 `violin_c.wav`、`piano_c.wav`、`sax.wav`、`noise.wav`。
  2. 先听四段声音，再统一读成 22050 Hz、单声道数组。
  3. 查看小提琴的样本数；运行 `np.fft.fft`，确认输出长度与输入样本数相同。
  4. 对复数结果使用 `np.abs`，得到每个频率格的幅度。
  5. 建立频率轴，用 `f_ratio=0.1` 只显示 0—2205 Hz，而不是删除高频后重新计算。
  6. 按小提琴、钢琴、萨克斯、噪声的顺序画四张谱并比较。
  7. 在源实验之后补两处必要校正：`rfftfreq` 精确配对单边 FFT；每张谱以自身峰值为 0 dB 时只能比较轮廓，不能比较谁更响。
- 源材料中的技术校正：Notebook 用 `np.linspace(0, sr, N)` 生成横轴，最后一点会比真实 DFT 频率高一个频率间隔；实现改用 `fftfreq` / `rfftfreq`。Notebook 文件名写 Power Spectrum，但代码计算的是 `np.abs(X)`，因此正文称“幅度谱”，不把它误写成功率谱。
- 实验问题：同一段录音的 FFT 输出是否与样本一一对应，四种真实声音在 0—2205 Hz 的幅度谱轮廓又有什么不同？
- 验收标准：每段音频统一为 22050 Hz 单声道；`len(fft(y)) == len(y)`；`len(rfft(y)) == N // 2 + 1`；频率轴由 NumPy 配套函数产生；图中所有数字来自同一次 `--dump`；四段素材按 Notebook 顺序出现。
- 代码：`NotebookLM课程博客_重写版/课程代码/lessons/lesson14_fft_spectrum.py`
- 必须输出：四段素材的原始采样率、统一后的样本数和时长；小提琴的输入/输出长度；峰值复数及其模；`f_ratio=0.1` 对应的显示上限；四段声音在可见范围内最突出的频率。
