# 第 23 课任务卡：频谱质心与带宽

- 源文件与范围：
  - 可执行主线：`source_course/23 - Spectral centroid and bandwidth/Spectral centroid and bandwidth.ipynb`，20 个单元格。
  - 逐格文字：`NotebookLM课程博客_重写版/PPT内容/23-Spectral-Centroid-and-Bandwidth.md`。
  - 补充参考：`notebooklm博客/ダウンロード (11).md`，是 Markdown 博客稿，不是 `.ipynb`。
- 上一课交进来：读者已经会在真实 Hz 轴上逐帧统计频谱，并知道矩阵哪一维是频率。
- 读者问题：频谱的中心和展开程度怎样手算，怎样确认库函数用的是同一个定义？
- 一句话结果：质心是以幅度为权重的 Hz 加权平均；librosa 默认带宽是围绕该质心的均方根距离（`p=2`）。手算与库逐帧对齐后，才可以比较三段录音的时间轨迹。
- 本课拥有的新概念：质心与带宽的手写向量化实现；`p=1` 平均绝对距离与 `p=2` 均方根距离的区别；静音帧的解释边界。
- 只回顾：两个特征的直觉和公式回链第 21 课；STFT、频率轴和矩阵方向只回链。
- 明确边界：不把三个音频样本的差异写成流派规律；不再扩展新的模型或深度学习内容。
- 按源 Notebook 排列的讲解块：
  1. 载入 debussy、redhot、duke。
  2. 设 `FRAME_SIZE=1024`、`HOP_LENGTH=512`。
  3. 调 `librosa.feature.spectral_centroid`，看 shape，换成秒，画三条曲线。
  4. 调 `librosa.feature.spectral_bandwidth`，看 shape，再画三条曲线。
  5. 编辑补充：把两行库函数手写出来，并逐帧核对。
- 必要校正：
  - 第 21 课源材料的带宽公式是 `p=1`；librosa 在本课未写参数时默认 `p=2`。正文必须把两者并排说明，并以 `p=2` 对齐库。
  - 权重使用幅度谱，不使用功率谱；与第 22 课 BER 的功率口径明确区分。
  - 静音帧算出的 0 Hz 只是库的数值约定，没有可解释的“频谱中心”。
- 实验问题：按同一套参数手写质心和 `p=2` 带宽，能否与 librosa 逐帧相同；`p=1` 与 `p=2` 在真实音乐上会差多少？
- 验收标准：
  1. 三段录音的质心、带宽 shape 与时间轴长度全部对齐。
  2. 手写质心与库的最大绝对差、手写 `p=2` 带宽与库的最大差都打印。
  3. 打印 `p=1`、`p=2` 的中位数及比值，不能把两套定义混报成一个值。
  4. 打印三段录音质心与带宽的中位数、四分位区间及两条轨迹的相关系数；如结果不支持“高度相关”，正文照实写。
  5. 所有正文数字和配图来自同一次 `--dump`。

## 零基础与术语自查

- “质心”不是音高；一堆泛音和噪声会一起拉动它。
- “带宽”不是文件码率，也不是滤波器通带；它只说这一帧频谱围绕质心铺得多开。
- `p=2` 的平方和开方必须成对出现，结果单位才仍是 Hz。
- 不在正文提及源文件、幻灯片、Notebook 或制作过程。
