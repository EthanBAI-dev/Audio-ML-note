## 2. 标题要重写（用户明确指出不好）

现有六个标题：

```
波形、频谱与声谱图：电脑识别声音时该“看”什么？
波形、频率与音高：屏幕上的声音曲线记录了什么？
分贝、响度与音色：为什么“音量一样”听起来仍不同？
采样率与位深：44.1 kHz 和 16 bit 决定了什么？
音频特征怎么选？理解抽象层级、时间尺度与模型输入
分帧、加窗与聚合：怎样把整段录音变成可计算的小段？
```

看得出来的问题：

- **六篇里五篇是同一个模子**：`术语A、术语B与术语C：一个问句`。一个系列全长一样，读起来像自动生成的。
- **术语顶在最前面**。零基础读者看到的第一样东西是三个专业名词，而正文第一段却在讲手机小程序、录音软件、音量条——**标题和开头不是一个调子**。
- **冒号后面那半句才是给人看的**，前半句是给搜索引擎看的。现在的排序把两者放反了。
- 第 05 篇又换成了另一种句式（问号在中间），系列内部也不统一。

还没确认的：用户只说「标题起的不好」，没说具体想要什么方向。**下次先问清楚**，候选方向至少有三种：

1. 把问句提前，术语退到副标题或正文。
2. 用结论当标题（「整段平均一次，敲击就找不回来了」）。
3. 保持信息型但拆掉那个固定模子，让六篇各有各的句式。
