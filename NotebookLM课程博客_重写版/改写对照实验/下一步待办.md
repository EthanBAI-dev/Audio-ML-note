## 2. 标题已按用户意见重写（2026-09-02 第二轮）

用户给的原则：**一定要说明白主语和谓语。** 生活化的例子是手段，但必须让读者知道它和主体是什么关系。**简单又明了才是追求。**

改后：

| 课 | 新标题 |
| --- | --- |
| 01 | 电脑读录音的三种方式：波形、频谱与声谱图 |
| 02 | 录音软件里那条线记下了什么？——波形、频率与音高 |
| 03 | 音量一样，为什么听起来不一样？——分贝、响度与音色 |
| 04 | 采样率和位深：电脑录音时定下的两个数 |
| 05 | 该从录音里算出什么交给模型？——音频特征的四个选择 |
| 06 | 整段录音太长，先切成小段：分帧、加窗与聚合 |

同一轮还改掉的坏词（用户逐条点名）：

| 原文 | 问题 | 改成 |
| --- | --- | --- |
| 同一段录音有三种**整理方式** | 「整理」通常指整理文件，和主题接不上 | 电脑**读**一段录音，有三种方式 |
| 可以**摆成三种样子**给程序看 | 计算机不是人，不会摆样子 | 有三种常见的**读取**方式 |
| **摆错了姿势**，关键证据就没了 | 同上 | **读取方式选错了**，你要找的那个特征就已经丢掉了 |
| 三种**摆法** / 重新**摆**一遍 | 同上 | 三种**读取方式** |

**文件名还没改**（仍是旧标题）。改文件名会牵动 23 篇里的相互链接，等定稿一起做。

**02–06 的正文还没有逐句过这一关**。这次只改了标题、导读，以及 01、05 里用户点名的句子。下次要按同样的标准通读一遍：主语谓语在不在、例子有没有连回主体。
