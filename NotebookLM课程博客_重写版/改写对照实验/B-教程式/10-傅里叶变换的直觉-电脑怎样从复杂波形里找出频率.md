# 电脑怎样从一团混在一起的波形里找出频率？——傅里叶变换的直觉

> **导读：** 前四课算出来的数只回答“有多响、抖得多密”，答不出最基本的一个问题：**这段声音里有哪些高低成分？** 麦克风收到的是所有振动加在一起的结果，看上去像一团乱线。这一课不写特征，只做一件事：**拿一支已知频率的波去乘这段声音，再求平均。** 频率对上了，平均值不为零；对不上，正负自己抵消成零。全部运算只有乘法和平均，跑一遍就能把 440 和 880 从混合波形里挑出来。

## 这一课要做的事

简单来说：**要知道一段声音里有没有某个频率——也就是每秒来回振动多少次——就用那个频率的一支干净的波去乘它，把乘出来的结果求平均。** 平均值明显不为零，说明这个频率在声音里确实存在，而且平均值的大小正好就是它的强度；平均值接近零，说明这个频率不在里面。

把这件事对很多个频率各做一遍，得到的一串数就是**频谱**——一张“哪个频率有多强”的清单。这就是**傅里叶变换**做的事，去掉数学包装之后只剩乘法和平均。

**为什么值得花一整课讲直觉？** 因为后面十几课全部建在它上面：声谱图、梅尔频谱、MFCC，全是这一步的加工品。这里没想通，后面就只能背函数名。

## 为什么不能直接从波形上“看”出来

麦克风把它收到的所有振动加在一起，只输出一条曲线。**两支同时响的波，加起来的那条线既不像第一支，也不像第二支。**

  <img src="../../零基础版_06-10/figures/desktop/10-two-sines-add.svg" alt="440 Hz 与 880 Hz 两条正弦相加得到的复杂波形">
</picture>

*图 1：上面两条是各自干净的振动（440 Hz 幅度 1.0、880 Hz 幅度 0.5），最下面那条是它们相加的结果——麦克风只输出这一条。三格画的是同一段 0.05 秒，横轴一格对一格。*

前面几课的三个特征都答不了这个问题，原因是它们的算法里根本没有“频率”这个概念：

| | 振幅包络 / 均方根 | 过零率 | 试探法（本课） |
|---|---|---|---|
| 它在数什么 | 数字有多大 | 正负号翻了几次 | 某个指定频率有多强 |
| 能说出“有 440 Hz 吗” | 不能 | 不能 | 能，还能说出多强 |
| 混进第二个频率会怎样 | 只知道总强度变了 | 次数变多，说不清为什么 | 两个频率各自读出一个数 |

**什么时候需要走到频率这一步：** 要判断音高、要分辨两件乐器、要认出说的是哪个字、要找出机器在哪个转速上共振——这些差别全在频率的分布里。

**什么时候不需要：** 只关心“有没有声音”“什么时候变响”，前面三个特征更便宜也更稳。**不要因为傅里叶变换更“高级”就默认用它。**

## 心智模型：一次问答分三步

整套做法说白了是**拿一支已知频率的干净波去和这段声音比相似**：像得多，说明这个频率在里面占的分量大。**「比相似」这件事分三步走，后面三节各讲一步：**

| 步 | 做什么 | 讲在 |
|---|---|---|
| ① 选一个频率 | 定下这一次要问哪个频率，造一支这个频率的干净波 | 核心概念一 |
| ② 对齐起点 | 试一遍起点，找出和信号对得最齐的那一个 | 核心概念三 |
| ③ 量出强度 | 两条曲线逐点相乘，算乘出来那条曲线下面的面积 | 核心概念一、二 |

第 ③ 步的「面积」和后面代码里的「求平均」是同一件事：**平均值就是面积除以样本个数**。用面积去想更容易看懂图，用平均去算更方便写代码。

把 ①—③ 对很多个频率各做一遍，问出来的一串数就是频谱。

## 核心概念一：同频相乘，正负不再抵消

先看一个能手算的现象。**两支波逐点相乘，再对乘出来的一整串数求平均，结果取决于两支波的频率是不是同一个：**

- **频率相同**：两支波同时为正、同时为负，乘积**永远是正的**（负乘负也得正）。求平均，得到一个明显大于零的数。
- **频率不同**：有时同号、有时异号，乘积一会儿正一会儿负。跨过足够长的时间，正的部分和负的部分**互相抵消，平均值趋近于零**。

  <source media="(max-width: 640px)" srcset="../../零基础版_06-10/figures/mobile/10-probe-match.svg">
  <img src="../../零基础版_06-10/figures/desktop/10-probe-match.svg" alt="同频与不同频试探波相乘后的平均结果">
</picture>

*图 2：上排两支频率相同，乘积整条都在中线上方，平均值大；下排频率不同，乘积上下摆动，平均下来接近零。*

我们把用来相乘的那支已知频率的波叫**试探波**。用 $R(f)$ 表示试探频率 $f$ 得到的读数，整个过程写出来是

$$
R(f)=\frac{2}{N}\sum_{n=0}^{N-1}x[n]\,\sin\!\left(2\pi f\frac{n}{f_{\mathrm{s}}}\right)
$$

$x$ 是录音，$N$ 是样本个数，$f_{\mathrm{s}}$ 是采样率，$f$ 是你要试探的频率。**乘 2 是一个约定**：这样当声音里正好含有一支幅度为 $A$ 的同频波时，读数正好等于 $A$，不用再换算。

```python
def probe(x, freq, sr):
    t = np.arange(len(x)) / sr
    return float(2 * np.mean(x * np.sin(2 * np.pi * freq * t)))
```

**常见错误：试探的时间太短。** “不同频率会互相抵消”要成立，需要覆盖足够多个来回。只取十几个样本，两支不同频率的波还没来得及错开，读数就不是零——凭空多出一个并不存在的频率。

## 核心概念二：把试探频率扫一遍，就得到频谱

一次试探只回答一个频率。**把试探频率从低到高逐个试过去，每个记下一个读数，把这些读数按频率排开，就是频谱。**

  <img src="../../零基础版_06-10/figures/desktop/10-sweep.svg" alt="试探频率从 100 扫到 2000 Hz 得到的频谱">
</picture>

*图 3：横轴是试探频率，纵轴是读数。只在两处立起来，其余整条贴着零——那两处就是这段声音真正含有的频率。*

所以**频谱不是从波形里“提取”出来的**，而是**一个个问出来的**：你问了 951 个频率，它给了你 951 个回答。这个说法比“变换”更贴近实际发生的事。

**你问哪些频率、问多密，是你自己定的。** 这一点在后面几课会变成一个具体的限制：真正的傅里叶变换只在一组固定间隔的频率上给读数，间隔多大由样本数和采样率决定，不能任意加密。

## 核心概念三：一支试探波会被起点位置抹掉

上面的做法有一个漏洞。**同一段声音，只是录制的起点稍微挪了一点，用一支正弦试探波去问，读数可能从 1.0 掉到 0。**

原因是相乘要“对得上”：如果试探波和声音里那支波正好错开四分之一个来回，一半时间同号、一半时间异号，乘积的正负部分恰好抵消，读数变成零。**声音里明明有这个频率，试探波却说没有。**

<picture>
  <source media="(max-width: 640px)" srcset="../../零基础版_06-10/figures/mobile/10-phase-kills.svg">
  <img src="../../零基础版_06-10/figures/desktop/10-phase-kills.svg" alt="单支试探波会被起点位置抹掉，两支合起来则不会">
</picture>

*图 4：同一段声音只把起点挪四分之一圈，一支试探波的读数从 1.0 掉到 0；换成两支合起来，两次都是 1.0。*

**解决办法是同时用两支试探波**：一支正弦、一支余弦，它们正好错开四分之一个来回。哪一支对不上，另一支就一定对得上。把两个读数当成直角三角形的两条直角边，**斜边的长度就是不受起点影响的强度**。正弦那一支的读数记作 $R_{\mathrm{s}}$、余弦那一支记作 $R_{\mathrm{c}}$，强度 $M(f)$ 就是

$$
M(f)=\sqrt{R_{\mathrm{s}}^{2}+R_{\mathrm{c}}^{2}}
$$

顺带还有一个赠品：两个读数的比例说明这支波是**从哪个位置起步的**，这个位置叫**相位**——[第 02 课](02-波形频率与音高-声音曲线记录了什么.md)讲振动的三个旋钮时提过它，这里第一次真正用上。

**这就是第 11 课要引入复数的全部理由。** 复数不是为了显得高深，而是因为“两个必须成对出现的读数”用一个复数写起来最省事：实部放余弦读数，虚部放正弦读数，强度就是它的长度，相位就是它的方向。

## 动手实验：用乘法和平均，把 440 和 880 挑出来

**这一节要做的事：** 自己造一段成分完全已知的声音——440 Hz 幅度 1.0，加上 880 Hz 幅度 0.5——然后用试探法把这两个数**原样读回来**。因为答案事先就知道，任何一位小数对不上都能立刻发现问题出在哪。

环境和音频素材装一次就够，见[课程总纲的「动手之前」](../../课程总纲/README.md)。本课完整代码在 [`课程代码/lessons/lesson10_fourier_intuition.py`](../../课程代码/lessons/lesson10_fourier_intuition.py)，脚本里还有两个正文放不下的实验：把成分加回去重建原波形，以及把同一套试探用在真实钢琴录音上。

### 第 1 步 — 造一段声音，问它三个频率

```python
import numpy as np

SR = 4000                                   # 这一课用一个小采样率，1 秒 4000 个数
t = np.arange(SR) / SR
sig = np.sin(2 * np.pi * 440 * t) + 0.5 * np.sin(2 * np.pi * 880 * t)

def probe(x, freq, sr=SR):
    tt = np.arange(len(x)) / sr
    return float(2 * np.mean(x * np.sin(2 * np.pi * freq * tt)))

for f in (440, 500, 880):
    print(f, round(probe(sig, f), 4))
```

```text
440 1.0
500 -0.0
880 0.5
```

**三个读数正好是答案本身。** 逐个读：

- **440 读出 1.0000**，而我们放进去的幅度就是 1.0。试探法不只说“有”，还说出了“有多强”。
- **880 读出 0.5000**，同样和放进去的 0.5 一模一样。**两个频率混在同一条曲线里，互相没有干扰**——这是“不同频率相乘会抵消”带来的好处。
- **500 读出 −0.0000**，也就是零。这个频率不在声音里，正负部分完全抵消掉了。

**注意这里没有用到任何库函数。** 全部运算是一次逐点相乘、一次求平均、乘以 2。傅里叶变换的核心就是这几行，剩下的都是让它跑得快、跑得规范的工程。

### 第 2 步 — 把试探频率扫一遍

```python
freqs = np.arange(100, 2001, 2.0)
mags = [probe(sig, f) for f in freqs]
```

```text
一共试了 951 个频率
最高：440 Hz 读数 1.0000
次高：880 Hz 读数 0.5000
其余 949 个最大只有 0.0000
```

**其余 949 个频率的读数全是零，一个假峰都没有。** 这条由 951 个读数排成的曲线，就是这段声音的频谱。

要留意这个干净结果的前提：**信号是我们自己造的，两个频率都在整整 1 秒里走完了整数个来回。** 真实录音做不到这一点，扫出来的峰会有一定宽度，旁边还会有小的起伏——那是第 06 课加窗要解决的问题，第 14 课会正面处理。**先在理想情况下把机制看清楚，再去面对真实数据，比反过来容易得多。**

### 第 3 步 — 把起点挪四分之一圈，看一支试探波怎么失灵

把信号里的两支 `sin` 换成 `cos`，等于把起点挪了四分之一圈。**声音含有的频率和强度一个都没变**，只有起步位置变了：

```python
sig_c = np.cos(2 * np.pi * 440 * t) + 0.5 * np.cos(2 * np.pi * 880 * t)

print(round(probe(sig, 440), 4), round(probe(sig_c, 440), 4))
```

```text
1.0 -0.0
```

**第二个读数是 0——可这段声音里明明有 440 Hz。** 不是声音变了，是试探波和它错开了。

补上余弦那一支，取直角边长：

```python
def magnitude(x, freq, sr=SR):
    tt = np.arange(len(x)) / sr
    s = 2 * np.mean(x * np.sin(2 * np.pi * freq * tt))
    c = 2 * np.mean(x * np.cos(2 * np.pi * freq * tt))
    return float(np.hypot(s, c))

print(round(magnitude(sig, 440), 4), round(magnitude(sig_c, 440), 4))
```

```text
1.0 1.0
```

**两次都是 1.0，起点挪到哪里都不影响。** 顺带把起步位置也读出来了：两段声音在 440 Hz 上的相位分别是 1.5708 和 0.0000 弧度，相差正好 $\pi/2$，也就是四分之一圈——和我们做的改动完全对上。

**这一步是本课最值钱的一处。** 只用一支试探波的程序，在真实录音上会时不时报出“这个频率不存在”，而错误无法从结果上看出来。**两支成对使用不是可选项。**

### 加一层：把读数加回去，能不能拼回原来的波形

既然读数说这段声音由 440 和 880 两支波组成，那把它们按读到的强度和位置加回去，应该能得到原波形：

```text
只用 440 和 880 重建
逐点最大误差 2.11e-15
```

**2.11e-15 是浮点运算的残渣，等于完全一致。** 这说明试探法读到的不是近似值，而是这段声音的完整描述——**信息一点没丢，只是换了一种写法**：原来按时间排，现在按频率排。

这一步有自己的名字：从频谱回到波形叫**逆傅里叶变换**；而「把一堆按强度和起点加权的干净波叠起来，造出一个复杂声音」这件事本身，在电子音乐里叫**加法合成**。**同一套数学，正着用是分析，反着用是合成。**

（这里能完全重建，是因为信号本来就只由这两支波组成。真实录音要重建，得把所有频率的读数都留着，包括相位。）

### 加一层：同一套试探，用在真实钢琴录音上

```text
1 秒钢琴录音，扫 100–2000 Hz
最高点  527 Hz 读数 0.1819
2 倍处 1054 Hz 读数 0.0251
3 倍处 1581 Hz 读数 0.0012
```

**最高点 527 Hz 离标准音 C5 的 523 Hz 只差 4 Hz**，这段录音弹的确实是这个音。更有意思的是 2 倍频率处还有主峰 14% 的读数：**乐器发出的从来不是一支干净的波，而是基本频率加上一串整数倍的成分**，这些整数倍叫**泛音**。

第 03 课说过“同一个音高、不同乐器听起来不一样”，差别就在泛音的分布上。**到这里，那句话第一次变成了可以量的东西。**

### 加一层：整段做一次，时间就没了

把一段“前半秒 440、后半秒 880”的声音，和一段顺序完全相反的声音，各扫一次：

| | 440 Hz 读数 | 880 Hz 读数 |
|---|---|---|
| 先低后高 | 0.5000 | 0.5000 |
| 先高后低 | 0.5000 | 0.5000 |

**两段声音顺序完全相反，读数一模一样。**

*图 5：整段做一次，只得到一条频谱，答不出“第几秒”；先分帧、每帧各做一次，把结果一列列排开，时间就回来了。*

**时间信息是在“求平均”那一步被抹掉的**——平均把整段压成一个数，先后顺序自然就没了。这不是缺陷，是这个方法的定义决定的。

找回时间的办法你已经学过一半了：**第 06 课的分帧。** 先把录音切成小段，对每一小段各做一次试探，再把结果一列列排开，就得到一张横轴时间、纵轴频率的图。这就是第 15 课的**短时傅里叶变换**，和第 16 课的声谱图。

## 这三处最容易把结果算错

**边界：试探的时长决定分不分得开两个相近的频率。** “不同频率会抵消”需要时间。取样只有 0.1 秒时，440 Hz 和 445 Hz 在这段时间里几乎没错开，读数会糊成一团。**能分开的最小频率差，大致就是 1 除以试探时长**：1 秒能分开 1 Hz 左右，0.1 秒只能分开 10 Hz。这条取舍在第 15 课会正式出现。

**数值稳定性：乘 2 这个约定不是普适的。** 不同的库有不同的归一化方式，有的除以 $N$，有的除以 $\sqrt{N}$，有的什么都不除。**读数的绝对大小换个库就变了，能跨库比较的是形状和相对大小。** 每次换工具，先用一个已知幅度的正弦波试一遍，确认它的约定。

**可复现：频谱的横轴要连采样率一起记。** 读数本身只是一串数，“第 7 个数对应哪个频率”取决于采样率和样本个数。第 13 课专门讲这个换算——**它是这门课里最常写反的一处**。

## 常见问题

**Q1：这一课的做法和真正的傅里叶变换差在哪？**

差在两处，都是工程上的：**第一，真正的变换只在一组固定间隔的频率上取读数**，不像这里可以任意指定；**第二，它用一种叫快速傅里叶变换的算法**，把逐个频率去问的计算量大幅降下来。**原理完全一样**：都是拿已知频率的波去乘，再求平均。

**Q2：为什么非要两支试探波，一支不行吗？**

一支能给出读数，但那个读数同时受“这个频率有多强”和“它从哪个位置起步”两件事影响，你分不清读到的 0 是“没有这个频率”还是“起点正好错开”。**两支合起来，强度和起步位置就分开了**——这也正是复数的两个部分要表示的东西。

**Q3：结果不对怎么排查？**

按这个顺序：

1. 先用一支纯正弦波试，试探频率就取它自己。读数应该等于它的幅度。对不上就是那个乘 2 的约定或者采样率写错了。
2. 试一个肯定不存在的频率，读数应该接近 0。不接近 0，多半是试探时长太短。
3. 检查时间轴 `t` 是不是用了正确的采样率。**这是最常见的错误**：`t = np.arange(n)` 少除了一个采样率，所有频率就全错了位。
4. 换成两支试探波取直角边长。如果单支为 0、双支不为 0，那就是起点错开的问题，不是数据问题。

**Q4：实际项目里最该注意什么？**

**别急着调库。** `np.fft.fft` 一行就能出结果，但它返回的是复数、横轴要自己换算、幅度要自己归一化、单边双边要自己决定——这四件事任何一件搞错，图都画得出来，只是错的。**先手写一次试探法，你才有能力判断库给你的结果对不对。**

## 接下来学什么

1. **第 06—09 课**：沿着时间看录音，算出三个便宜的数。
2. **本课**：用乘法和平均，问出“某个频率有多强”。
3. **第 11 课**：把成对出现的两个读数写成一个复数。
