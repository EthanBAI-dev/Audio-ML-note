# 第 06～10 课：零基础知识主线改写版

本组属于[课程总纲](../课程总纲/README.md)的第 06-10 阶段：**把录音变成可计算片段**。

每篇末尾的「动手做」对应[课程项目《三首曲子，一个分类器》](../课程项目/README.md)的不用频谱，先看时间（第 6—10 步）。

本批采用的完整步骤已整理为[《零基础科普文章改写与配图工作流》](../零基础改写与配图工作流.md)，后续文章沿用同一方法。

## 配图

共 20 张知识图，每张由同一份数据生成桌面和手机两个版式：

- `figures/desktop/`：880 px，适合并排比较。
- `figures/mobile/`：420 px，改为纵向阅读；缩到 360 px 正文宽度后，最小有效字号不低于 12 px。

波形和特征曲线优先使用 `source_course/audio_resources/` 中的真实音频；用于解释公式的正弦波、孤立尖峰等图使用参数明确的合成数据。手机端不会删除桌面图中的机制与说明，横向对照表会转置成纵向卡片。

生成与检查：

```bash
node tools/build-figures-06-10.mjs
node tools/build-figure-contact-sheets.mjs both 06-10
node ".agents/skills/audio-course-lesson/scripts/check-svg-mobile.mjs" \
  "NotebookLM课程博客_重写版/零基础版_06-10/figures/mobile"
```

Claude Code 可以把上面命令中的 `.agents/skills/` 换成 `.claude/skills/`；两份项目 skill 已同步。
