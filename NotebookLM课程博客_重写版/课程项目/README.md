# 课程项目：三首曲子，一个分类器

> **一句话目标：** 让程序听 1 秒钟的音乐片段，判断它来自古典、爵士还是摇滚。

这不是一个额外的作业包，而是把 23 课串起来的那条线。每一课的实验都是这个项目的一步，对应 [`课程代码/lessons/`](../课程代码/README.md) 里的一个脚本；23 步做完，你手里会有一套自己写的音频特征工具、一张特征表，以及一个能说清楚"它凭什么这么判断"的结果。

## 为什么是这个题目

课程自带三段音乐，正好来自三种风格：

| 文件 | 风格 | 听起来的特点 |
|---|---|---|
| `debussy.wav` | 古典（德彪西） | 钢琴，起伏平缓，高频成分少 |
| `duke.wav` | 爵士（Duke Ellington） | 管乐与节奏组，中频厚 |
| `redhot.wav` | 摇滚（Red Hot Chili Peppers） | 失真吉他与鼓，高频密集、能量满 |

它们的差别足够明显，人一听就分得出；但**要让程序分出来，就必须把"听起来不一样"翻译成可计算的数字**——这正是整个课程在做的事。

另外七段音频用于对照和检查：`piano_c` 与 `violin_c`（同一个音高、不同音色）、`sax`、`scale`（上行音阶）、`tremolo`（周期性颤音）、`voice`（语音）、`noise`（噪声）。

## 最后交出什么

```text
project/
├─ soundlab/            # 你自己写的工具包，一课加一点
│  ├─ io.py             # 读音频、统一采样率与声道
│  ├─ framing.py        # 分帧、加窗
│  ├─ time_features.py  # 振幅包络、RMS、过零率
│  ├─ spectral.py       # FFT、STFT、频谱统计
│  └─ mel.py            # 梅尔频谱、MFCC
├─ dataset.csv          # 每个 1 秒片段一行：文件、起止时间、风格标签
├─ features.csv         # 每个片段一行：全部特征 + 标签
└─ report.md            # 三种风格在各个特征上的差别，以及最后的判断结果
```

**最后一步不是训练一个深度模型。** 这套课程的范围停在"为识别程序准备可信的输入"，所以收尾要回答的是：**我算出来的这些数字，真的能把三种风格分开吗？** 用散点图看，用最近邻算一个参考准确率，然后说明是哪几个特征在起作用。

## 23 步怎样连起来

### 第一阶段 · 打地基（01—05）

先把数据准备成能反复使用的样子。这一段几乎不写特征，但后面每一步都依赖它。

| 课 | 这一步做什么 | 产出 |
|---|---|---|
| 01 | 定下要分辨什么，确认三段主素材和七段对照素材都在 | `dataset_manifest.csv` |
| 02 | 从声音怎样产生走到波形，再验证音高编号和赫兹的关系 | `soundlab/io.py` 的读取函数与音高换算练习 |
| 03 | 分清声功率、声强、分贝、响度和音色，并比较三种音色线索 | 一份不会把“录得更响”当成音色的观察规则 |
| 04 | 统一采样率，理解为什么参数不一致会毁掉整个数据集 | 固定的预处理参数 |
| 05 | 用五个维度列出三分类任务可能需要的特征 | 一张特征选择表 |

### 第二阶段 · 不用频谱，先看时间（06—10）

只用波形本身就能算出的三种特征。它们便宜、直观，而且已经能分开一部分风格。

| 课 | 这一步做什么 | 产出 |
|---|---|---|
| 06 | 写分帧函数，把每个片段切成许多小段 | `framing.py` |
| 07 | 观察三种时域特征在三种风格上的差别 | 一张对比图 |
| 08 | 实现振幅包络 | `time_features.py` 的 `amplitude_envelope` |
| 09 | 实现 RMS 与过零率，写出第一版特征表 | `features.csv` 的前几列 |
| 10 | 手写一次"用已知频率去试探"，理解频谱从哪来 | 一个能跑通的匹配实验 |

### 第三阶段 · 进入频率（11—15）

从"这段声音有多响"走到"这段声音由哪些频率组成"。

| 课 | 这一步做什么 | 产出 |
|---|---|---|
| 11 | 用复数同时表示强弱和起始位置 | 一组小练习 |
| 12 | 用复数探针做单频匹配，看清幅度与相位 | 匹配实验的复数版 |
| 13 | 把连续公式变成有限 DFT，验证逆变换、镜像和 FFT 加速 | 一个手写 8 点 DFT 实验 |
| 14 | 按 Notebook 顺序读取四段真实声音，正确配对单边 FFT 与 Hz 横轴 | `spectral.py` 的 `rfft_magnitude` 和四张低频谱 |
| 15 | 实现 STFT，得到时间—频率矩阵 | `spectral.py` 的 `stft` |

### 第四阶段 · 整理成模型输入（16—20）

把上千个频率成分压缩成几十个数字，并让它更接近人的听觉。

| 课 | 这一步做什么 | 产出 |
|---|---|---|
| 16 | 画出三种风格的声谱图，统一比较条件 | 三张可比较的声谱图 |
| 17 | 构造梅尔三角滤波器组 | `mel.py` 的滤波器矩阵 |
| 18 | 提取对数梅尔频谱，固定并记录参数 | `mel.py` 的 `log_mel` |
| 19 | 用 DCT 把轮廓压到前几项 | 对 13 维取舍的理解 |
| 20 | 计算 MFCC 与 Delta，拼成每帧 39 维 | `mel.py` 的 `mfcc39` |

### 第五阶段 · 概括与验证（21—23）

用少量可解释的数字概括频谱，然后检验整套特征到底管不管用。

| 课 | 这一步做什么 | 产出 |
|---|---|---|
| 21 | 想清楚带能量比、质心、带宽各自回答什么 | 特征选择说明 |
| 22 | 实现带能量比 | `spectral.py` 的 `band_energy_ratio` |
| 23 | 实现质心与带宽，合并全部特征，检验能否分开三种风格 | 完整 `features.csv` + `report.md` |

## 开始之前

建一个工作目录，把课程音频和代码复制进去：

```bash
mkdir -p project/audio
cp source_course/audio_resources/*.wav project/audio/
cp -r 课程代码/soundlab 课程代码/lessons project/
cd project
python -m pip install -r ../课程代码/requirements.txt
python lessons/lesson01_course_map.py
```

每一课的实验脚本都假设你在 `project/` 目录下工作。环境准备的完整说明在[课程总纲](../课程总纲/README.md)，代码的目录结构在[课程代码的 README](../课程代码/README.md)。

## 三条贯穿始终的纪律

1. **参数写下来。** 采样率、帧长、帧移、窗函数、`n_fft`、`n_mels`、归一化方式——任何一个改了，特征表就不能和之前的比较。把它们集中放在一个 `config.py` 里，不要散落在各处。
2. **先检查形状，再看数值。** 每次新写一个函数，先打印输出的 `shape`，确认哪一维是时间、哪一维是频率。矩阵转置写反是这门课最常见的错误。
3. **每一步都要能解释。** 如果某个数字算出来了但你说不清它代表什么，它对最终判断就没有价值——这比准确率高几个点重要得多。
