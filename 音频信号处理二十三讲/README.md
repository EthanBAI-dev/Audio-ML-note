# 音频信号处理与机器学习：23 课中文课程

面向没有相关背景的读者，从"电脑怎样看见声音"讲到梅尔频谱、MFCC 和频域统计特征。全程围绕一个项目展开：**让程序听 1 秒钟的音乐片段，判断它来自古典、爵士还是摇滚。**

## 这套文章怎么写的

- **假设读者一无所知。** 任何专业词第一次出现前，先用日常语言讲清楚它指什么，讲完才给名字。
- **深度顺序不写在明面上。** 从具体现象出发，逐步走到公式、代码和适用边界，但不会出现"第一层/第二层"这类结构标注。
- **每篇只回答一个问题。** 相邻文章不重复承担同一概念；需要深入的地方用正文内链接跳转。
- **公式、代码、单位和适用边界一个都不省。** 简化只发生在讲解方式上，不发生在技术内容上。

写作与配图的完整方法见[《零基础科普文章改写与配图工作流》](../参考资料/改写与配图工作流.md)，规则与检查脚本在项目内的 skill 里（`.claude/skills/` 与 `.agents/skills/`，两份同步）；源课程逐页全文与概念归属表在仓库的 `参考资料/` 目录。

## 配图

每篇 5 张左右，共 122 张，每张同时有电脑版（880 px 横排）和手机版（420 px 竖排），由同一份数据、同一段代码生成，正文用 `<picture>` 按屏幕宽度切换。

波形、频谱、声谱图一律来自真实计算——素材优先取 `source_course/audio_resources/` 里的课程音频，其次是与正文严格对应的合成信号。声谱图用 magma 色标（librosa 与音频论文的惯例），线图用通过色觉障碍校验的分类色。
